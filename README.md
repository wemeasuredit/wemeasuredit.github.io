# wemeasuredit.github.io

The public website for **We Measured It** — guides that take a claim somebody is
making, test it on an example small enough to follow, and say plainly how the
numbers came out.

Live at <https://wemeasuredit.github.io/>

| Path | What it is |
|---|---|
| `index.html` | The site's front page, listing the guides |
| `guides/tabfm/index.html` | The TabFM teaching guide |
| `guides/tabfm/tabfm_churn_demo.ipynb` | The runnable notebook behind that guide, opened straight from here in Google Colab |

Only finished, reader-facing work lives in this repository. The working material —
build scripts, review notes and measurements — stays in a separate private one.
